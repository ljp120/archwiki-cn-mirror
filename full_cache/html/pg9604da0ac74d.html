有许多方法可在特定事件发生时自动执行脚本或启动应用程序，本文提供了这些方法的链接。

开关机时

启用相关的 systemd 服务。如果应用程序没有提供 systemd 服务，请自行编写。

用户登录登出时

启用相关的用户单元。

插入拔出设备时

使用 udev 规则。

基于时间事件

在特定时间、日期或间隔定期执行：

  • systemd/Timers
  • Cron

仅在某日或某时执行一次：

  • systemd/Timers
  • at包

基于文件系统事件

使用 inotify 事件监视器：

  • inotify-tools包，参见 inotifywait(1)
  • incron
  • fswatchAUR
  • entr包
  • systemd 可以使用 systemd.path(5) 文件在文件系统事件发生时激活单元

shell 登录登出时

参见命令行解释器#配置文件。

Xorg 启动时

  • 如果使用 xinit 手动启动 Xorg，请参见 xinitrc。
  • 如果使用显示管理器启动，请参见 xprofile。

桌面环境启动时

大多数桌面环境实现了 XDG Autostart。

如果某个桌面环境有相关文章，请参见其“自动启动”（Autostart）章节。

  • GNOME#自启动
  • KDE#自启动
  • Xfce#自动运行
  • LXDE#程序自动开启
  • LXQt#自动启动
