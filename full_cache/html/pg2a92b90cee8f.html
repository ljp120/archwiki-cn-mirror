一些网站提供了网络订阅源（Web feed） 或 新闻订阅源 ，一般以 RSS， [Atom]，或 [JSON] 格式提供。 新闻聚合器可以读取这些订阅源的内容，检查这些内容是否有更新，从而让用户订阅博客或播客内容。

获取网络订阅源

即使一个网站并没有声明其拥有网络订阅源，也有可能提供这项服务。您可以尝试在网址后添加/feed或/rss来查看网站是否支持。如果这样还是不行的话，可以使用Ctrl+u查看网页源代码，然后使用Ctrl+f搜索<link rel="alternate" type="application/atom+xml"或<link rel="alternate" type="application/rss+xml"。火狐浏览器插件Awesome RSS会在访问支持网络订阅源的网站时于地址栏添加一个可以点击的图标。

如果网站不支持网页订阅源，可以试试这个应用RSS-Bridge.

以下章节描述了在特定网站上如何获得订阅链接。

GitHub

对提交commit订阅使用如下链接语法： 

https://github.com/user/repo/commits/branch/path/to/subdir.atom

Reddit

Reddit provides feeds for subreddits, posts and users: simply add .rss to the URL. If you have a Reddit account, you can find your personal feeds in the preferences.

Reddit提供RSS订阅链接。对于子版块、帖子和用户，仅需要在网址后添加.rss即可。如果你已经拥有Reddit账户，你可以在偏好中找到自己的订阅链接。

YouTube

订阅一个频道： 

https://www.youtube.com/feeds/videos.xml?channel_id=UCxxxxxxxxxxxxxxxxxxxxxx

如果这个频道使用以/user/username结尾的传统网址，你也可以使用： 

https://www.youtube.com/feeds/videos.xml?user=username

你可以从Google Takeout上下载你的订阅链接，然后使用这个项目将其转换为OMPL格式。
