模拟器被用于复制另一个平台或系统的功能，以允许应用程序和游戏在不支持的环境中运行。

注意：要获得更多最新的模拟器选择，请尝试检索 AUR 'emulator' 关键字。
警告：拥有一个高级模拟器是合法的，但是分发任何受版权保护的 ROMs 都是非法的。因此，Arch Linux 并不发布这些受版权保护的内容，包括游戏 ROM 和破解的主机 BIOS。您对使用从官方仓库或 Arch User Repository 获得的模拟器产生的任何法律后果负有全部责任。
