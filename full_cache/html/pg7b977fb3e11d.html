本页面尝试列出所有编程语言，包含适用于 Arch Linux 的已打包编译器/解释器。

  • Ada——Ada

  • Ballerina——ballerinaAUR

    • AOZ Studio
    • Gambas
    • QB64——qb64AUR
  • C——GCC、Clang

  • D
  • Dart——dart包
  • Erlang——erlang包
    • Elixir
  • Factor——factorAUR

  • Go——go包、GCC

    • Groovy——groovy包
  • GDL——gnudatalanguageAUR
  • Haskell
  • JavaScript——rhino包、v8AUR[损坏的链接：package not found]、quickjsAUR
    • Node.js
  • Julia
  • Kotlin——kotlin包
  • Lisp 方言
    • Clojure
    • Common Lisp
    • Emacs Lisp
    • Scheme
    • Racket——racket包、racket-minimal包
    • newLISP——newlispAUR

  • Lua——lua包、luajit包
  • ML
    • Standard ML——smlnj包、mlton包、polyml包、mosmlAUR、smlsharpAUR
    • OCaml——ocaml包
  • Nim——nim包
  • Octave
  • Pascal——fpc包、lazarus包
  • Perl
  • PHP
  • Python
  • QCL——qclAUR
  • R
  • Raku (Perl 6)——rakudoAUR
  • Ruby
  • Rust
  • Scala
  • Swift
  • Tcl——tcl包
  • Vala——vala包
  • Zig——zig包
