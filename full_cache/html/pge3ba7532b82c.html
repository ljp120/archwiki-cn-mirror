聊天群组通用规则

  • 请首先遵守各自聊天服务的服务条款。（例如 Librea.Chat 的网络政策和频道指南）和 Arch Linux 的行为准则。
  • 请勿在除 #archlinux-cn-nsfw 以外其他频道发送 NSFW(Not Safe For Work) 内容。
  • 加入频道以后先通过 /topic 或置顶消息读一下频道的话题,会包含这个频道相关的一些信息。
  • 由于群内成员组成不单一且位于各地，请避免使用容易令他人反感、容易造成争议或不便于 IRC 客户端提及的昵称。
    • Telegram 用户可以通过 /nick 查询和设置在 IRC 中显示的昵称。
  • 不要问能不能问，请直接问。
  • 频道内的机器人不止一个，不过也请不要滥用机器人指令。如果你想加入你自己的机器人，欢迎先来 #archlinux-cn-bot 测试。
  • 几个频道的成员基本相同，在一个频道提问后短时间没有回答请不要同时转发到别的频道。过分发布可能被视为 spam 行为。

不同聊天软件适用的指引

IRC 侧适用指引

  • 处于曾经遭受过来自 IRC 的大量 spam 攻击，上述部分 IRC 频道要求通过 TLS 接入 IRC ，非 TLS 连接可能会被重定向至 #archlinux-cn-unregistered 频道。
  • 不要刷屏，粘贴日志请考虑使用类 Pastebin 服务，如 https://fars.ee/ 。
  • 贴图同样可以用类图床服务，如 https://fars.ee/ 。
  • 不要对着桥接机器人说话，人类的名字在它们后面，请在回复时输入桥接机器人后面的昵称。用 weechat 客户端可以使用 bot2human 插件隐藏机器人姓名。

Telegram 侧适用指引

  • 入群请先关注新闻频道 @archlinuxcn， 随后可加入各个 Telegram 群组。未关注新闻频道状态下入群会被 spam 防范机器人踢出，请关注频道后稍候两分钟再次尝试。
  • 长的代码或者日志，请使用 Pastebin 服务，或者作为文件发送。
  • 由于 Bot API 的限制（Bot 之间相互不可见），由 Telegram 上的其他机器人发送的消息无法被其他侧的 IM 看到。引用 Bot 消息时请注意。
  • #archlinux-cn 和 #archlinux-cn-meta 禁止发送 Sticker 和 GIF ，可以发送图片和视频。请不要试图发送内容为贴纸的图片绕过此限制。
  • #archlinux-cn-offtopic 在 IRC 频道已经设置成只转发 Sticker 对应的 Emoji。图片、视频、语音、文档等如未超过大小限制会被正常转发到图床。
  • 由于存在转发机器人，请注意发布的信息中不要包括自己和其他人的隐私，已转发到 IRC 的消息无法被删除或修改。误发包含隐私信息的图片请联系图床管理员删除服务器存档（但是浏览器缓存无法控制），请联系落絮管理员删除被落絮索引的隐私信息。
  • 某些话题在 Telegram 上有相应的子群组，相应的群链接可以在 #archlinux-cn-offtopic 的置顶消息中找到。如果您的话题只与这些子话题相关，可以考虑利用。

Matrix 侧适用指引

  • 入群前请加入 #archlinux-cn-space:nichi.co。
  • 如果无法加入上述 space，请想办法联系管理员告知 Matrix ID 以获得邀请。（这是在 spam 猖獗时的临时措施。）
  • 来自 telegram_*:nichi.co 的用户是通过 Telegram 接入的，不支持私聊。由于技术限制，如果同一个人连续发出图片和文字，回复时请回复图片。

部分聊天频道的额外规则

#archlinux-cn 的额外规则

  • #archlinux-cn 频道的主要目的是讨论和支持 Arch Linux 。如果你正在使用某个 Arch Linux 的衍生发行版，非 Arch Linux 的 GNU/Linux 发行版，或者在不受官方支持的非标准环境中使用（例如 Windows Subsystem for Linux 中），请在提问前先说明。
    • 提问其它技术问题（例如和 Arch Linux 及其衍生发行版都不相关的 GNU/Linux 发行版相关（或无关）问题， Windows/macOS 相关问题，电脑硬件相关问题等）请移步 #archlinux-cn-offtopic，或是其它相关群组。
    • 管理员或其他成员在话题跑题或明显不属于 Arch Linux 相关话题时可能会要求移步至 #archlinux-cn-offtopic，如果被要求这样做或者转至私聊，请遵守这个要求，长时间发表无关话题且无意听从劝解的用户可能会被禁言或封禁。
  • 推荐阅读提问的智慧，一般来说，好的问题更容易更快地解决。另外提问前先试着用落絮搜索一下看看是否已经被其他人遇到并解决了。
  • 别依赖他人的帮助，尝试自己去寻找答案。重复提问前先等等，大多数问题都是由其他用户回答的，例如你。
  • 也别害羞，如果遇到你能回答的问题，请试着给予解答，只有更多的志愿者参与回答社群才能蓬勃发展。
  • 如果有其他人询问关于你的问题的更多信息，记得要及时回复。
  • 提问时请确保自己可以访问出现问题的系统，以便及时获取信息、进行诊断。请勿“离线提问”。（如果做不到，请考虑使用论坛。）
  • 除了提问涉及个人隐私或者违反了群组规定之类的情况之外，请不要擅自删除自己的提问。如果已经自己知道解答，可以在群内把结论告知大家。擅自删除提问，尤其是在已经有别人回复之后删除，会严重影响后来人阅读聊天记录。 我们不欢迎通过机器人或者聊天软件设置自动删除历史记录的行为。请理解我们的完整聊天记录通过 IRC 等其它形式已经公开在互联网上，删除 Telegram 等单方面的聊天记录没有保护隐私的意义，只会打乱聊天记录。
  • 请勿使用 DeepSeek、ChatGPT、Copilot 、Gemini、Claude、Qwen、Grok、LLaMa 或类似的 AI 引擎的输出当作参考。请勿就其输出内容提问，或者用之回答。提问时不必以其输出证明已尝试过 AI ，回答时也请不要建议询问 AI 。（如果你想问某个符合本群主题的 AI 输出是否正确，请直接假定它是错的。）
  • 社区交流的语言为中文和英文，请避免使用其他语言。提问或回答时如需引用或截图英文内容，请使用原文，不要使用机器翻译过的文本。

#archlinux-cn-offtopic 的额外规则

  • 尽管是 offtopic 群组，但请勿发送容易令普遍人群反感的内容（例如 NSFW 和明显的钓鱼内容）。
  • 请勿长时间争论容易造成争论的内容（例如宗教、体育、种族、民族主义和政治等），在管理员或成员提醒后仍坚持发表相关话题的成员可能会被封禁。
