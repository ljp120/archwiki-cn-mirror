图形处理器 (graphics processing unit, GPU) 是计算机中负责生成显示器所显示画面的硬件，也经常（不严谨地）称为显卡 (graphics card)。存在两种类型的设备：集成显卡 (integrated GPU, iGPU) 和独立显卡 (discrete GPU, dGPU)。在中文语境下，有时集成显卡也会不严谨地称为“核显”。

由于 GPU 擅长并行计算，因此催生了通用图形处理器 (GPGPU)。

安装

Linux 内核中已经包含了用于硬件加速帧缓冲的显卡驱动。然而，OpenGL、Vulkan、硬件视频加速和 Xorg 的 2D 加速仍然需要用户空间驱动支持。

首先，识别设备型号（输出中的第一行以及 Subsystem 一项显示了具体型号）： 

$ lspci -v -nn -d ::03xx
提示：这里的 ::03 表示“显示控制器 PCI 设备类”，并且 xx 表示“该类的任何子类”。您可以在安装 hwdata包 后，在 /usr/share/hwdata/pci.ids 文件中搜索 Display controller 查看。

然后，安装所需的显卡驱动。参阅下方三个品牌的表格。

对于 32 位软件，需要启用 multilib 仓库并安装以 lib32- 为前缀的用户空间驱动，例如 lib32-mesa包、lib32-vulkan-radeon包、lib32-nvidia-utils包 等等。

对于 X11，其它 Device Dependent X (DDX) 驱动可以在 xorg-drivers包组 中找到，或者可以搜索 xf86-video。大部分情况下，您不需要安装任何 DDX 驱动；详情参阅 Xorg#驱动安装。

AMD

AMD 支持开源驱动。曾经提供过一个专有驱动，但已经不再打包了。[1][2]

提示：要寻找从型号名（如 Radeon RX 6600）到 GPU 家族名（如 RDNA 2）的对照表，参阅 Wikipedia:List of AMD graphics processing units#Features overview.

有关各个 GPU 家族对 VA-API 的支持情况，参阅硬件视频加速#对照表了解详情。

Intel

Intel 提供并支持开源驱动，除了旧的基于 PowerVR 的显卡（GMA 3600 系列）不支持以外。

提示：Intel 所说的 Gen N 硬件并不是指 CPU 的代数，它指的是 GPU 的代数，和 CPU 的不一样。

NVIDIA

NVIDIA 不支持完全开源的驱动。他们从 2022 年起改为使用一种混合方案（开源内核 DRM 驱动和闭源用户空间驱动）。

提示：要寻找从型号名（如 RTX 4060）到 GPU 家族名（如 NV190）的对照表，参阅 nouveau wiki 上的代号页面。

参阅硬件视频加速#NVIDIA以了解支持哪些 API，并参阅硬件视频加速#VDPAU 驱动了解各个 GPU 家族的支持详情。

加载

大部分驱动的内核模块会在系统启动时自动加载。

如果没有自动加载，那么：

  • 确保您没有在内核参数中设置 nomodeset 或 vga=，因为加载内核显卡驱动需要内核级显示模式设置。
  • 以及，检查您是否使用内核模块#黑名单禁用了显卡驱动。

监控

监控 GPU 的工具经常用于查看 GPU 的温度、核心和显存 (VRAM) 使用率、以及 P-state。

CLI

  • amdgpu_top — 显示 AMDGPU 使用率的工具
https://github.com/Umio-Yasuno/amdgpu_top || amdgpu_top包
  • nvtop — 支持 AMD、Intel 和 NVIDIA 的 GPU 进程监视器
https://github.com/Syllo/nvtop || nvtop包
  • radeontop — GPU 使用率查看器，支持显示总体的活动百分比和各个部分的使用情况。支持 ATI R600 或更新的显卡，以及使用 AMDGPU 驱动的显卡。
https://github.com/clbr/radeontop || radeontop包
  • nvidia-smi — NVIDIA 专有驱动捆绑的命令行监控工具，支持 Fermi 或更新的 NVIDIA GPU
https://docs.nvidia.com/deploy/nvidia-smi/index.html || nvidia-utils包
